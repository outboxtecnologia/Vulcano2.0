# 💻 Linguagens e Stack do Vulcano

A separação do nosso arsenal tecnológico que dá vida ao Questor Explorer e ao Vulcano:

### Backend
- **Python 3.12+**: Coração lógico.
- **FastAPI**: Criação de rotas velozes e assíncronas.
- **Firebird / SQLite**: Motor de dados relacional e armazenamentos em memória/persistentes.
- **Uvicorn**: Servidor local em Python (porta 8000).

### Frontend
- **React + Vite**: Criação de interfaces ricas com recarregamento rápido.
- **Vanilla CSS (com CSS Variables)**: Sistema de design próprio (Tectonic Precision, Night Mode).
- **Sem proxy**: Comunicação direta do Vite (Porta 5173) ao FastAPI.
