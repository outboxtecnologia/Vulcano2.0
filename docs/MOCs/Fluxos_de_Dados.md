# 🌊 Mapas de Fluxos de Dados

Aqui documentamos a trajetória da informação, desde o envio do arquivo até sua alocação no banco Firebird/SQLite.

### Fluxos Principais
- **ETL de PDFs:** Sienge Fast-Path Regex -> Extração -> Conciliação -> Base de Dados.
- **Workflow de Conciliação:** Motor Questor vs Vulcano Legado vs Vulcano IFRS.
- **Fluxo do Frontend:** React (Port 5173) -> FastAPI (Port 8000).
